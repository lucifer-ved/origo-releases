# Origo for macOS

Downloads for [Origo](https://origo.tools), the control panel for your AI tools' MCP servers, skills and keys.

Get the latest version from the [Releases](../../releases/latest) page or from [origo.tools](https://origo.tools).

- Requires macOS 15 or later on Apple Silicon.
- Every download is signed with a Developer ID and notarized by Apple. Compare the SHA-256 in the release notes with `shasum -a 256 Origo-<version>.dmg`.
- Origo is free to use with up to 2 of everything. A Pro licence from [origo.tools](https://origo.tools) removes the limits.
- Installed copies update themselves.
